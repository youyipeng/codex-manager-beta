The sanitized JSON is a summary derived from internal records of a real Desktop run on October 5, 2026. It is not a fresh execution, signed third-party attestation or external customer case study.

Stage 5.1: one natural-language request; first implementation passed 30/31 tests; Manager rejected and requested a repair of leading/trailing ASCII-space handling; second implementation passed 31/31 with lint/typecheck/build passing and a separate review accepting. Only the allowed implementation file changed in the work copy; the original repo stayed unchanged.

External Beta 0.1.0-beta: separate final-ZIP installation checks and a one-iteration 16/16 demo. Internal install scripts took 29.074 and 42.261 seconds with dependencies and login ready, on the existing machine. These exclude download, extraction, manual actions and model execution. They do not prove a stranger's installation time or cross-machine compatibility.

The beta uses the verified repair core, but the 31-test repair sequence was not re-recorded on the final beta package. No real external trial has completed yet. No customer time-savings or payment claims are supported.

Passing tests can miss requirements, UX problems or untested defects. Keep human review and record disagreements with automated acceptance.
